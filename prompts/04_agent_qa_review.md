# Агент: QA и аудит (Astra, в конце каждой недели и перед записью)

Использовать вместе с промптом 00. Задачи T-19, T-22, T-23.

1. **Сценарный прогон**: пройти главный и дополнительный сценарии из `docs/02_product_spec.md`
   §3–4 в demo-mode три раза подряд. Для каждого шага: ожидалось / получилось / скриншот.
   Любое расхождение — отдельный пункт с путём к файлу и предполагаемой причиной. Не чинить.
2. **Аудит дизайна**: skill `mobile-design-review` по всем экранам. Выдать Design Score и
   AI Slop Score, список находок с рейтингом, 5 самых дешёвых исправлений с наибольшим эффектом.
   Цель перед записью: Slop ≤ 10, ни одной находки уровня «critical».
3. **Критерии ПГУ**: пройти по 10 критериям из `docs/01_tz_digest.md`, поставить
   прогнозную оценку 0/5/10 с обоснованием в одну строку. Для всего, что не 10, — что
   конкретно показать в ролике, чтобы стало 10.
4. **Стабильность**: 10 минут хаотичных нажатий по всем ролям; список красных экранов,
   зависаний, пустых состояний без текста.

Формат отчёта: четыре раздела выше, в конце — таблица «проблема → задача T-XX / новая».
