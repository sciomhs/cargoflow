# Агент: Экраны (GPT-6.1 Sol в Codex), по одной роли за прогон

Использовать вместе с промптом 00. Задачи T-09 … T-18.

Перед кодом: загрузить skill `mobile-taste`, прочитать `app/MOBILE-DESIGN.md`, `app/NAV.md`,
посмотреть `app/(dev)/ui-gallery.tsx` — использовать только примитивы из `src/ui/`.
Новый примитив = `DECISION NEEDED`.

Порядок внутри задачи: пустое состояние → состояние загрузки (skeleton) → состояние с данными
→ ошибка сети → счастливый путь. Все четыре должны быть видны в demo-mode (есть переключатель
в dev-меню).

Экран считается готовым, когда:
- данные приходят через `TripRepository`, не напрямую из seed;
- каждое действие пишет событие и видно на другом экране/роли без перезапуска;
- Android back и жест назад ведут туда, куда написано в `NAV.md`;
- у водителя: ни одного элемента управления меньше 56px, кнопка «следующий статус» одна;
- у клиента: нет полей `driver.phone`, `events.payload.internal`, стоимости;
- `tells.md` grep — 0 попаданий; скриншот экрана приложен к отчёту (путь в `app/screenshots/`).
