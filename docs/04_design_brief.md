# 04 — Дизайн-бриф (черновик `MOBILE-DESIGN.md`)

Этот файл копируется в `app/MOBILE-DESIGN.md` и дорабатывается skill'ом
`mobile-design-system`. Все агенты обязаны ему следовать. Правки — только через
оркестратора.

## App Read
- **Тип:** рабочий инструмент (ops tool), не consumer-app. Используется в кабине грузовика, на складе, в диспетчерской.
- **Аудитория:** водители 30–55 лет, часто в перчатках, на солнце; диспетчеры за столом, много данных; клиенты — менеджеры снабжения, открывают раз в день; руководитель — раз в неделю.
- **Вайб:** «дорожный документ». Спокойный, плотный, честный. Как хорошо напечатанная накладная, а не как финтех-стартап.
- **Платформа:** Android-first (Казахстан), iOS совместимо. Нативные паттерны Material, но без фирменного Material-лилового.

## Дилы (dials)
- `DESIGN_EXPRESSION`: **2 из 5** — сдержанно. Характер даёт типографика и один акцент, не декор.
- `MOTION_INTENSITY`: **1 из 5** — только функциональные переходы (сдвиг таймлайна, смена статуса). Никаких parallax, bounce, конфетти.
- `VISUAL_DENSITY`: **диспетчер 4/5, водитель 2/5, клиент 3/5.** Плотность зависит от роли.

## Цвет
- Основа — тёплые нейтрали, не чисто белый: фон `#F4F2EE` (светлая тема), поверхность `#FFFFFF`, текст `#1A1917`, вторичный `#5E5A54`, линии `#DCD8D0`.
- **Один акцент — глубокий зелёный «на маршруте» `#1F6F4A`.** Используется для primary-кнопки, активного таба, текущего этапа таймлайна. Больше ни для чего.
- Семантика: задержка/проблема `#B4411F` (ржавый, не алый), ожидание `#8A6D1F` (охра), завершено `#4E7A5F` (приглушённый зелёный). Фон семантических плашек — 10% тон.
- Тёмная тема для водителя ночью: фон `#141311`, поверхность `#1E1C19`, акцент тот же.
- **Запрещено:** градиенты, индиго/фиолетовый, «AI-blue» `#6366F1`, неон, glassmorphism.

## Типографика
- Текст: **IBM Plex Sans** (есть кириллица, выглядит документно). Fallback — системный.
- Номера рейсов, веса, госномера, время: **IBM Plex Mono**, `tabular-nums`. `R-642`, `8 500 кг`, `777 ABC 14` всегда моно.
- Шкала: 12 / 14 / 16 / 20 / 28. Заголовки экранов — 20 regular, не bold-28. Цифры на дашборде — 28 mono.
- Разрядка тысяч пробелом, ₸ после числа: `32 500 ₸`. Даты: `22 окт, 14:30`.

## Форма и компоненты
- Радиус **6**. Не 16, не 24. Кнопки и поля — одинаковый радиус.
- Списки — не карточки. Строки с разделителем 1px, без тени. Карточка допускается только для одного «героя» на экране (текущий рейс водителя).
- Статус — **текстовая плашка** с цветной точкой слева, не цветная капсула на весь текст.
- Таймлайн — вертикальная линия слева, точки на этапах, текущий — заполненный акцентом, время справа моно.
- Иконки — **Lucide** через `lucide-react-native`, 20px, stroke 1.75. Никаких эмодзи.
- Кнопка водителя «следующий статус»: высота 64, во всю ширину, прижата к низу с safe-area, подпись действия + под ней мелко «следующий: …».
- Цели нажатия ≥ 48 (водитель — 56). Отступы по сетке 4: 8 / 12 / 16 / 24.
- Пустые состояния — одна строка текста и одно действие. Без иллюстраций.
- Загрузка — skeleton строк, не спиннер на весь экран.

## Навигация (черновик, финализирует `mobile-nav-plan`)
- Табы: диспетчер 3, водитель 2, клиент 2, руководитель 1 (без таббара). **Нет плавающей круглой кнопки.**
- Создание (заказ, рейс, проблема) — полноэкранная модалка со своим заголовком «Отмена / Сохранить».
- Фото — нативный пикер, не кастомная камера.
- Android back всегда ведёт на предыдущий экран стека, из модалки — закрывает с подтверждением, если есть ввод.

## Тексты (UX-writing)
- Глаголы в кнопках: «Принять рейс», «Груз загружен», «Подтвердить получение». Не «ОК», не «Далее» где можно конкретнее.
- Без приветствий «Привет, Руслан! 👋». Экран водителя начинается с номера рейса и маршрута.
- Без восклицательных знаков в системных сообщениях.
- Ошибка сети: «Нет сети. Действие сохранено и отправится автоматически» — не «Упс!».

## Запреты (перед коммитом UI прогнать grep из `tells.md` mobile-taste-skill)
1. Градиенты любого вида на фонах и кнопках.
2. 5 табов, плавающая круглая кнопка посередине таббара.
3. Экран из стопки белых скруглённых карточек с тенью.
4. Эмодзи как иконки или в заголовках.
5. «Welcome back», «Привет, {имя}!», мотивирующие фразы.
6. Индиго/фиолетовый, `#6366F1`, `#8B5CF6`, Tailwind-дефолтные `indigo-*`, `violet-*`.
7. Радиусы 16+ на кнопках; `shadow-lg` на карточках.
8. Бесконечные skeleton-блоки и спиннеры по центру.
9. Иллюстрации «люди с ноутбуками» и 3D-иконки.
10. Lorem ipsum, John Doe, placeholder-картинки, `+7 999 999 99 99`.
11. Один и тот же layout для всех ролей — у водителя и диспетчера разная плотность.
12. Центрированные заголовки и центрированный текст в списках.

## Что считается «хорошо» (референсы по ощущению, не по коду)
Linear (плотность и статусы), Things 3 (спокойные списки), накладная/транспортный документ
(типографика), интерфейс кассового терминала (большие кнопки у водителя).
