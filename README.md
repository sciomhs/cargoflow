# CargoFlow — контроль доставки грузов

Учебный проект (ПГУ, 1 месяц). Мобильное приложение для логистической компании:
диспетчер → водитель → клиент → руководитель. Сдаётся видеороликом по 10 критериям.

Этот репозиторий — **стартовый комплект**: исследование, спецификации, дизайн-бриф,
схема БД, промпты для агентов и бэклог. Кода приложения здесь пока нет — его пишут
агенты (Codex / ChatGPT) по промптам из `prompts/`, оркестратор — Claude.

## Порядок запуска

1. `bash setup/install-skills.sh` — поставить skills (Claude Code / Codex).
2. Открыть `prompts/00_orchestrator_prompt_chatgpt.md`, вставить в ChatGPT (Astra) или
   Codex (GPT-6.1 Sol) как первое сообщение. Дальше — по задачам из `tasks/backlog.md`.
3. Код приложения создаётся в папке `app/` этого же репозитория.
4. GitHub **не создаём** до финала: `git init` локально, коммит на каждую задачу.
   Когда всё готово — `git remote add origin …` и один push.

## Принципы

- Один заказ проходит через всё приложение — это главное, что оценивается.
- Демо не должно зависеть от сети: есть seed-данные и demo-mode.
- Интерфейс на русском, валюта ₸, города Казахстана.
- Без «ИИ-слопа»: никаких индиго-градиентов, пяти табов с плавающей кнопкой,
  стопок белых карточек и эмодзи вместо иконок. См. `docs/04_design_brief.md`.
